# Graphite & Copper implementation

Implemented from the approved page drafts using existing application behavior and real records. Mockup sample rows and timestamps are not hardcoded into the application.

Graphite: #24262B. Page: #FBF8F4. Copper accents: #D58C62. Primary control: #98522E. Active surfaces: #EEE3D7. White panels use 12-pixel corners and subtle shadows. Body copy is 16 pixels; secondary copy is at least 15 pixels, mostly 16. Controls are at least 44 pixels high. Details remain readable rather than shrinking to fit a single screenshot.

Included pages: landing, sign-in, registration, overview, cases, issue submission, knowledge, case investigation, investigation history, saved investigation, operational records, ROI, feedback, settings (preferences/team/catalog/policy), and guide. Evidence, records, and activity remain separate tabs. Full cited procedures retain their original wording and thresholds. Resolution remains separate from approval. Exports remain JSON and PDF. Invitations remain one-use codes.

Actual layouts adapt to screen size and content length; preview images were visual references, not pixel-exact functional specifications. Motion uses short transitions, disclosures, button states, and honest background-job progress. Reduced-motion users get immediate changes.

Desktop workflow changes in 1.4 are documented in WORKFLOW-UPDATE.md.
