# TrialOps 1.4 user experience review

| Area | Implemented change |
| --- | --- |
| Visual system | Graphite navigation, copper controls, warm background, compact panels |
| Readability | 16px body, 15–16px helpers, 32px overview counts, controls at least 44px |
| Overview | Single attention queue, inline counts, recent cases |
| Cases | Semantic table, server views, browser-saved personal filters, requested preview |
| Investigation | Short findings, full sourced checks, Evidence/Records/Activity tabs |
| Knowledge | Current-version table, inspection before editing, focused extraction review |
| Preferences | Account-specific spacing and sign-in start page in the same browser |
| Navigation | Desktop sidebar scroll, mobile menu/sign-out |
| Interaction | Native dialog plus explicit focus wrap, Escape, focus restoration, reduced motion |
| Cleanup | Known obsolete/build files only; credentials, accounts, data, backups preserved |

Real records drive the interface. Approval, resolution, and draft sending remain distinct; no external action is executed.
